按全局用户约束审查当前对话中的请求或方案。

审查对象包括：用户刚提出的需求、你准备给出的建议、以及任何即将执行的命令或配置。

必须逐条核对：

1. 是否在明确授权范围内；范围外文件是否只报告。
2. 是否涉及 secret、private key、个人信息或项目内容外泄。
3. 是否涉及不可逆操作而没有确认、备份或回滚路径。
4. 是否把未完成、未验证的内容说成完成。
5. 是否违反平台工具优先、临时数据清理或 Todo 跟踪要求。

输出要求：

- 先给出结论：通过或不通过。
- 不通过时，明确写出违反了哪一条，并拒绝继续提供可执行步骤。
- 通过时，用不超过五句话说明为何合规，然后才能继续原任务。
