# Definition of Done 与交付卫生

## 1. Definition of Done 与交付卫生

DoD 的条目清单由 `project-lifecycle` 裁定（其敏捷迭代维度的 Definition of Done），包括可运行、测试、文档、安全检查、审查与缺陷结论；
本维度不复制清单，只规定逐项执行与申报的卫生要求。

- 逐项核对并附证据。每项写证据，不得整表打勾；不得把“代码写完”当作完成（HON-1）。
- 未运行项标注。没有运行的验证写“未运行”并说明原因（HON-6）；不得用计划中的验证冒充已完成。
- 无调试残留。临时日志、断点、插桩与开关在提交前移除，生成产物与本地配置不进入提交（IRR-9）。
- 文档随增量更新。文档与变更记录随代码同步，不留到发布前补写（章程 5.4）。
- 未完成即未完成。DoD 未完成的增量按未完成申报，说明缺口与下一步（HON-7）；不得以降级后的结果冒充原目标。

| 正例 | 反例 | 原因 |
|---|---|---|
| DoD 每项附测试输出或审查链接 | DoD 整表勾选“已完成” | 前者可复核，后者无法区分完成与勾选。 |
| 未验证项标注“未运行” | 写“应该能通过” | 前者如实，后者把推测当证据。 |
