# Definition of Done 与交付卫生

## 1. Definition of Done 与交付卫生

DoD 是“这个增量做完了”的可判定定义，不是自愿声明。没有 DoD，完成就靠感觉。

- 逐项核对。实现可运行、相关测试通过、文档与变更记录同步、安全与依赖检查完成、审查通过、已知缺陷有结论；每项写证据，不得整表打勾。
- 未运行项标注。没有运行的验证写“未运行”并说明原因；不得用计划中的验证冒充已完成。
- 无调试残留。临时日志、断点、插桩与开关在提交前移除；生成产物与本地配置不进入提交。
- 文档随增量更新。运行手册、变更记录与注释随代码同步，不留到发布前补写。
- 未完成即未完成。DoD 未完成的增量按未完成申报，说明缺口与下一步；不得以降级后的结果冒充原目标。

| 正例 | 反例 | 原因 |
|---|---|---|
| DoD 每项附测试输出或审查链接 | DoD 整表勾选“已完成” | 前者可复核，后者无法区分完成与勾选。 |
| 未验证项标注“未运行” | 写“应该能通过” | 前者如实，后者把推测当证据。 |
