# 在制品控制

## 1. 在制品控制

在制品上限、阻塞项标记与插队记录的规则由 `project-lifecycle` 裁定（其敏捷迭代维度的迭代节奏与 WIP 节），
并行隔离（工作树或模块）由 `vcs-collaboration` 裁定；本维度不复制阈值与流程。

构建期间本 skill 只保留两条衔接要求：

- 到达上限时按 `project-lifecycle` 的规则先完成、评审或清理，不得以绕行方式并行。
- 受阻项按 `project-lifecycle` 的阻塞规则写明原因、责任人与解除条件后再转回待办，不得以“排队”掩盖阻塞。

| 正例 | 反例 | 原因 |
|---|---|---|
| 上限为三，满了先评审再开工 | 同时开七个任务，都“做了一半” | 前者持续产出完成项，后者全是半成品。 |
| 阻塞项带原因与解除条件 | 阻塞项只标“等一等” | 前者可追踪，后者无人负责解除。 |
