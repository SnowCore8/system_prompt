# 增量可运行

## 1. 增量可运行

增量的意义在于每个时点都处于可评审、可回滚的状态。大变更不拆步，等于把风险攒到最后一刻。

- 每步可构建可测试。任一步完成后构建与相关测试通过；判据：从任一提交切出分支能否立即运行。
- 主干保持可运行。未完成的特性不得破坏主干；确需并行的，用特性开关或独立工作树隔离。
- 大变更拆成可回滚步骤。数据库迁移、框架替换等拆为可独立验证与回退的小步；失败时回退一步而不是全部。
- 增量可演示。每个增量结束能演示可运行结果，不以“完成 80%”充当交付。
- 阻塞不扩散。某个增量受阻时，其余增量继续，受阻项带原因与解除条件。

| 正例 | 反例 | 原因 |
|---|---|---|
| 迁移分“加列、双写、切换、清旧”四步 | 一次性改表改码改配置 | 前者任一步失败可回退，后者只能整体抢救。 |
| 主干随时可构建 | 特性开发期间主干长期编译失败 | 后者使评审与集成无从进行。 |
