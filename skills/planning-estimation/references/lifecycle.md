# 计划与估算生命周期契约

本文件规定本 skill 在 S0–S7 中的职责、门禁证据、交接与升级、裁剪与度量。阶段与门禁编号由生命周期治理模型裁定；本 skill 主责 S2 设计中的计划部分，在 S1 核对输入、在 S3 跟踪偏差、在 S7 复盘对照。

## 阶段职责

### S1 需求

- 输入：需求说明、验收标准与收益基线。
- 活动：核对需求可判定、验收标准存在、收益基线可衡量；登记已暴露的风险与外部依赖。
- 产出与证据：计划输入核对结论、初步风险与依赖清单。

### S2 设计

- 输入：G1 结论与计划输入。
- 活动：拆分任务并给出估算依据；按依赖排关键路径与里程碑；登记风险与跨团队依赖；固定计划基线。
- 产出与证据：任务清单、估算记录、关键路径、风险登记、依赖登记、G2 证据。

### S3 构建

- 输入：G2 结论与计划基线。
- 活动：跟踪任务状态与剩余工作量；记录偏差；范围或日期变化时先写变更请求再重新过门。
- 产出与证据：进度对照记录、偏差说明、变更请求。

### S7 收尾

- 输入：发布与运维记录、进度与范围数据。
- 活动：对照基线复盘估算准确性、进度偏差与风险应对效果；把结论沉淀为可复用的估算基准。
- 产出与证据：复盘结论、行动项与负责人。

## 门禁证据

| 门禁 | 证据形态 | 判定 |
|---|---|---|
| G1 需求 | 计划输入核对结论、初步风险与依赖 | 输入完整为 Go；缺失时 Hold 或 Recycle 到 S1 |
| G2 设计 | 任务清单与估算依据、关键路径、风险登记、依赖登记、基线 | 关键依赖已确认且基线可复核为 Go；否则 Hold |
| G3 构建 | 进度与基线对照记录、偏差说明、变更请求 | 状态可追溯为 Go；基线静默变化时 Recycle 到 S2 |

证据必须可复核：估算要能追溯到依据，依赖要能追溯到对方的确认记录；“预计可用”不构成承诺证据。

## 交接与升级

- S1 → S2：把计划输入与初步风险交给计划者；输入不可判定的退回 S1。
- S2 → S3：把任务清单、里程碑与基线交给交付方；关键依赖未确认的部分标注为未承诺。
- S3 → S7：把进度对照与变更请求交给复盘者；缺失的对照记录先补齐再复盘。
- 升级：同一任务连续两次 Recycle 未解决、关键依赖持续未确认或基线反复变更时，升级到有权决定者并重新评估范围或目标。
- 停止：出现安全或不可逆风险、授权变化或依赖失效时停止排期，报告受阻项与已确认项。

## 裁剪与度量

- R0：任务清单加验收句即可，估算可只写区间；仍须记录风险与停止条件。
- R1：精简计划：任务、估算、里程碑、风险登记与依赖登记；G2 由项目负责人确认。
- R2：完整计划与独立评审；跨团队依赖必须有对方确认与失败回退，日期承诺需发起人批准。
- 度量：以估算偏差率、里程碑达成率与基线变更次数为准；偏差持续扩大时先查拆分与依据质量，不得调目标。
