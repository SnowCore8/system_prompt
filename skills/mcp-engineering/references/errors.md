# 错误语义

## 1. 错误结构

- 失败返回结构化错误：稳定错误代码、面向调用方的一句话信息、可选的结构化数据。
- 错误代码按类别分组（参数、状态、权限、不可用），不按内部异常类型暴露。
- 不伪造成功：部分完成必须报告哪些完成、哪些未完成，不得返回成功结果掩盖失败。

## 2. 失败路径与日志

- 信息不足时返回缺失字段，不猜默认值；权限不足时说明需要什么权限，不静默返回空结果。
- 错误信息写给调用方，不含堆栈、内部路径、主机名或凭据；诊断细节写服务器日志并带关联标识。
- 每个工具写明失败路径：参数错、状态不对、依赖不可用、超时分别返回什么。
- 日志不落请求中的机密与个人信息；审计需要时记录脱敏摘要。
