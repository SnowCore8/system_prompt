# 传输与会话

## 1. 传输与会话
- 一个 stdio 服务器只服务启动它的那个客户端进程：stdin/stdout 承载协议消息，服务器退出即会话结束。
- 协议帧只写 stdout；stderr 只写日志，stdout 上的任何非协议输出都会使客户端解析失败。
- 适用于本地单用户工具；多个客户端共享同一服务器时改用 HTTP。

## 2. HTTP 传输

- HTTP 传输用会话标识把请求归到同一会话；服务器必须保留并接受客户端回传的会话标识。
- 端点只放协议路由；认证、限流与审计在网关或服务器入口处理，不放进工具。
- 超时、断开与重连要可恢复：无状态工具优先，有状态工具写明确认与重试语义。

## 3. 会话与生命周期

- 启动时做能力宣告与依赖校验，依赖缺失时以清晰错误退出，不静默降级。
- 退出路径干净：关闭资源、落盘状态，以退出码区分正常与异常。
- 会话内的状态变更可观测：记录连接、工具调用与失败，便于排查与审计。
