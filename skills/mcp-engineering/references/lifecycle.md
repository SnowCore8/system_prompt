# MCP 服务器与工具工程生命周期契约

本文件回答：MCP 服务器与工具工作在哪一阶段产生哪一类证据，证据不足时停在哪里。阶段与门禁的编号与判定
语义由 `project-lifecycle` 裁定；本文件把该框架落到工具契约、注册配置与版本，不重述门禁定义。维度规则见
对应维度文件。

## 阶段职责

| 阶段 | 输入 | 活动 | 输出 | 门禁 |
|---|---|---|---|---|
| S0 受理 | 请求对象与现有注册 | 判定涉及服务器、工具、注册还是调用方，记录风险级别 | 受理结论 | G0 |
| S1 需求 | 服务对象与工具边界 | 确认能力范围，比较自建与复用 | 工具清单、复用结论 | G1 |
| S2 设计 | G1 结论与平台能力 | 定传输、契约 schema、错误目录与安全边界 | 契约、注册方案 | G2 |
| S3 构建 | G2 计划 | 实现服务器与工具，schema 与实现同源 | 可运行服务器、一致 diff | G3 |
| S4 验证 | 增量与测试环境 | 跑契约测试与注入样本，手动冒烟，复核权限与机密 | 测试输出、审查结论 | G4 |
| S5 发布 | G4 结论与逐次同意 | 发布版本与变更记录，落地注册配置，准备回滚与公告 | 版本记录、注册结果 | G5 |
| S6 运维 | 调用指标与错误日志 | 监控失败率，执行弃用与兼容计划 | 指标、弃用记录 | G6 |
| S7 收尾 | 下线计划 | 公告下线，清理注册配置，归档契约与测试 | 下线记录、归档位置 | G7 |

S4 只验证 S2 已确定的契约与错误目录，不在验证阶段重新设计；发现契约缺陷按 Recycle 回到 S2 修订。

## 门禁证据

| 门禁 | 证据形态 | 复核者 | 不可接受的证据 |
|---|---|---|---|
| G2 | 工具清单与契约 schema；传输与注册方案；错误目录；安全边界 | 接口所有者与安全复核 | 只有工具名清单，无 schema 与错误路径 |
| G3 | 服务器可运行记录；schema 与实现一致 diff；失败路径处理 | 提交者自检；R1 起加独立审查 | 手工改写生成物；伪造成功结果 |
| G4 | 契约测试输出；注入样本结果；手动测试记录；权限与机密复核 | 独立审查者；R2 加安全结论 | 只测成功路径；机密复核缺失 |
| G5 | 版本与变更记录；注册配置落位；回滚方式演练；下线与弃用公告 | 运营与发布批准人 | 无回滚路径；未公告的破坏性变更 |

- R0：只改描述措辞或补文档，可把 G2 与 G4 记录合并，仍须跑契约测试。
- R1：新增工具或参数，至少一名非作者审查。
- R2：涉及生产写操作、凭据或权限的工具，G4 需要独立安全结论，G5 需要逐次同意。
- 例外（如临时放宽枚举）必须有所有者、范围与到期条件，并写入变更记录或门禁记录。
- 证据链接指向测试输出、diff 与注册配置，不指向口头承诺。

## 交接与升级

交接：

- 交 `prompt-engineering`：工具清单、描述与错误语义，供调用方写工具指令。
- 交 `release-operations`：版本策略、注册时机与回滚步骤。
- 交 `security-compliance`：权限边界、机密注入方式与审计要求。
- 交 `naming`：错误代码的命名形态；工具名与参数名的选择由本 skill 裁定。
- 交 `documentation`：用户可见的工具说明与弃用公告。

升级：

- 平台能力不支持所选传输或特性：Recycle 到 S2 换方案。
- 两个工具职责重叠：先合并再实现，不发布互相打架的入口。
- 注册配置无法安全落位：停止发布并报告。
- 同一问题连续两次 Recycle 未解决：升级决策层，重新评估方案或目标。
- 强制规则之间冲突：报告用户裁决，并把所选约定记录于契约。

停止条件：

- 未取得逐次明确同意时不得注册涉及生产写操作、凭据或权限的工具。
- 发现注册配置或日志写入真实凭据时按 SEC 条款停止并报告。
- 契约测试在错误路径上失败时停止发布，不得只验证成功路径。

## 裁剪与度量

裁剪：

- R0：一条受理兼计划记录；保留契约测试输出。
- R1：完整契约与错误目录但可精简；独立审查一名。
- R2：不得裁剪；契约、错误目录、安全结论与回滚演练四项证据必须同时存在。

度量：

| 指标 | 定义 | 用途 |
|---|---|---|
| 调用失败率 | 工具调用中结构化失败的比例 | 判断契约与错误语义质量 |
| 参数往返成功率 | 首次调用即通过 schema 校验的比例 | 发现描述与 schema 失配 |
| 弃用窗口时长 | 从标记弃用到移除的时长 | 校准兼容承诺 |
| 契约漂移数 | schema 与实现不一致被发现的次数 | 判断同源维护是否有效 |
| 注册配置事故数 | 因注册配置导致的调用中断次数 | 校准发布与回滚演练 |

审查节奏：每个发布周期复核一次度量与错误目录；异常先查契约口径与流程根因，再调整阈值。
