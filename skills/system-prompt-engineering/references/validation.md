# 常驻指令文件校验

## 1. 机器校验

机器校验覆盖可自动判定的项，退出码 0 表示通过：

- 行宽不超过 200 字符；行尾无空白；文件不使用制表符。
- 代码围栏成对；标题层级不跳跃；文件以单个换行结尾。
- 相对链接指向存在的文件；链接锚点可解析。
- 校验命令在 CI 中以严格模式运行，警告视为失败并在源头消除。

机器校验只判断格式，不判断语义：规则是否可判定、禁止项是否给替代、示例是否覆盖边界，都要人工逐条判断，
两者结论分开记录，不得用格式通过掩盖内容问题。

## 2. 人工校验

- 逐行适用删除标准：删除该行若不会阻止任何具体错误，就删除。
- 只在部分任务用到的细节移入对应 skill 或文档，正文保留摘要与加载指引。
- 检查未确认的工具、命令与配置键：写进文件前必须能在仓库或配置中核实。
- 检查占位符与待填项：不得保留未标记的 TODO 或虚假值。
- 检查两条规则是否冲突：触发条件、例外与失败路径必须闭合，每条规则可判定。
