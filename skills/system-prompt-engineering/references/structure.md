# 常驻指令文件结构

## 1. 节骨架

- 目标与范围：一两句话写明对象、范围与完成定义。
- 指令：应做的行为与禁止的行为分开；禁止项每条附理由。
- 工作流：仅当步骤顺序影响结果时写入，并说明跳过某一步的后果；否则只写目标与约束。
- 输出格式：写明结构、长度与格式；需要机读结果时声明结构化输出或 JSON Schema。
- 示例：每个示例用独立分隔标记包住，展示规则未覆盖的行为；边界情况并入示例。
- 上下文：只放左列的仓库事实，其余改为链接；任务不需要的节直接删除。

## 2. 复杂逻辑表达

- 多个条件选出一个动作的，用判定表：条件列用布尔值或枚举，写明匹配顺序与默认分支。
- 任务随事件在状态间迁移的，用状态表：列出当前状态、事件、条件、下一状态与动作，未列出的组合适用默认分支。
- 表格与图并存时表格为事实依据，图仅为概览；两者冲突以表格为准。
- 表格重复或嵌套超过两层时，拆下级判定、改用伪代码或带表驱动测试的纯函数。
