# API 与数据

API 契约与数据库 schema 是系统中生命周期最长的接口：外部调用方据其构建，背后的数据会累积多年。改字段会
让作者看不见的客户端失效；删列、未分批的迁移或让每个写入者排队的锁，都会导致数据丢失或服务中断；这些
后果都不是回滚代码能修复的。本 skill 规定契约的设计、审查与变更方式，数据库在不中断服务前提下的演进
方式，以及数据在生命周期结束后的退役方式。

## 适用范围与优先级

效力层级自上而下，高层覆盖低层：

1. HTTP 语义、所用 IDL（OpenAPI、protobuf、GraphQL）、数据库引擎行为与数据保护义务等强制约束。
2. 本 skill 的规则：契约设计、演进、迁移与数据保留。
3. 项目既有契约、迁移工具、错误码目录与兼容性策略属于事实输入，依本 skill 的规则处理；项目约定仅在本
   skill 未规定处补充。
4. 个人偏好，不得覆盖以上三层。

管辖与边界：

- 名称归 `naming`：资源、字段、表、列、索引与枚举的名称由该 skill 管辖，本 skill 管围绕名称的契约与流程。
- 索引的查询收益与写入放大权衡归 `performance`；本 skill 管 schema 形态与 DDL 影响。
- 删除与保留的隐私策略归 `security-compliance`；本 skill 使用其数据清单并执行保留期。
- 迁移的执行编排、部署顺序与停止条件归 `release-operations`；本 skill 交付迁移方案与验证查询。
- 影响评估默认按破坏性处理；经证明并非破坏性的不在此限，证明是消费方清单加上针对真实客户端的契约测试。
- 强制规则冲突时报告用户裁决；非强制的项目约定冲突说明所选约定并记录于契约或 ADR。

## 生命周期定位

上游输入：G1 确认的范围与结果指标、`security-compliance` 的数据清单、`performance` 的查询与索引目标。
下游交接：契约文件与生成物交 `code-style` 排除格式化，交 `documentation` 同步参考页；迁移与回填步骤交
`release-operations` 执行；契约 diff 校验与契约测试交 `testing-quality` 纳入 CI。升级与停止：消费方清单
不完整、销毁性变更缺验证过的恢复点、版本策略与项目承诺冲突时停止实施，报 Hold 或 Recycle；两项强制规则
冲突时报告用户裁决。

| 阶段 | 职责 | 产出与证据 |
|---|---|---|
| S0 受理 | 判定变更触碰契约还是数据，记录风险级别与停止条件 | 受理结论与影响面初判 |
| S1 需求 | 确认消费方与使用量，评估破坏性变更的选项 | 消费方清单、使用量数据 |
| S2 设计 | 定义 IDL、错误模型、分页与幂等契约、授权边界与 schema 形态，确定两步增量或版本边界 | 契约 diff、迁移与回滚方案、锁估算、保留与删除路径 |
| S3 构建 | 按扩展-收缩阶段实现，生成物由 IDL 重生成，契约测试随增量编写 | 可运行增量、生成差异为空、契约测试、回填脚本 |
| S4 验证 | 以前一客户端版本验证兼容性，在生产规模数据上验证锁与延迟，逐存储验证删除传播 | 契约测试输出、锁与复制延迟数据、删除回执 |
| S5 发布 | 复核销毁性迁移的批准、备份与试运行计数，迁移作为独立步骤执行 | 批准记录、恢复点、试运行计数、变更后查询 |
| S6 运维 | 监控回填与清理任务，处理契约与数据事故 | 任务运行记录、事故处置结论 |
| S7 收尾 | 执行数据退役与归档，核对保留期与删除路径 | 退役记录、保留核对结果 |

## 门禁与证据

契约 diff 的基线取最近发布标签，不取当前分支，使并行变更不能互相掩盖破坏。

| 门禁 | 必须提供的证据 | 不满足时 |
|---|---|---|
| G2 设计 | 契约 diff、消费方清单、两步增量或版本边界声明、迁移与回滚方案、锁估算、每个新字段的保留与删除路径 | Hold：消费方清单或恢复点缺失；Recycle 到 S1：版本策略与支持窗口冲突 |
| G3 构建 | IDL 与实现一致的 CI 输出、生成物重生成后差异为空、契约测试、回填脚本的幂等与游标 | Recycle 到 S3：手工编辑生成物，或破坏性变更未走两步增量 |
| G4 验证 | 前一客户端版本的契约测试、双跑结果、锁与复制延迟数据、约束验证查询、删除传播的逐存储回执 | Hold：兼容性未测或删除传播未验证；No-Go：销毁性变更无测试过的恢复路径 |
| G5 发布 | 迁移独立执行的记录、已验证的备份或时间点恢复点、试运行计数、变更后查询、销毁性变更的逐次同意 | Hold 或取消发布：批准缺失或恢复点未演练；不得以部署代替迁移 |
