# 授权边界

## 1. 授权边界

授权按对象检查，不按路由检查：在检查对象之前即返回数据的端点，属于带测试套件的数据泄露。

- 在边缘认证、在资源处授权：每个操作说明其检查的主体、租户与对象。
- 租户与所有者来自已验证的令牌，不得来自请求体或查询参数。
- 凭据缺失或无效返回 401，已认证但被拒绝返回 403，资源存在性本身敏感时返回 404。
- 授权变更即契约变更，遵循相同的版本化与废弃路径。
- 内部端点与管理端点通过与公共端点相同的策略检查；调试绕过即更换名称的公共端点。

## 2. 判定与边界

- 令牌作用域必须窄到仅覆盖该操作所需的最小权限；内部操作持窄作用域令牌调用，不经过公共网关。
- 401、403 与 404 遵循一套有文档的存在性策略，使客户端能判断重新认证、停止还是隐藏存在性。

## 3. 正反例

| 正例 | 反例 | 原因 |
|---|---|---|
| 对象级授权，租户来自令牌 | 按路由检查，租户来自查询参数 | 对象 ID 可枚举，路由遗漏即泄露 |
| 缺少令牌 401，被拒绝 403 | 每个失败都返回 403 | 客户端无法判断应当重新认证还是停止 |
| 内部端点走同一策略 | 调试端点绕过鉴权 | 绕过点即公共端点 |
