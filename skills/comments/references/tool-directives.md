# 工具指令

## 1. 工具指令

- 指令是供机器读取的代码，精确匹配工具的语法与范围，放在工具读取它的位置。
- 使用能起作用的最窄范围：先一行，再一个函数，再一个文件；不为一个位置在仓库范围禁用规则。
- 每条指令附理由，按工具支持的形式给出：`// eslint-disable-next-line no-console -- CLI output is the product.`
- 抑制不构成修复：文件级抑制还必须留下清理工单，说明何时可以移除。
- 语言支持时优先用注解或属性而非注释；配置属于配置文件，不属于某次调用之旁。
- 不再抑制任何对象的过时指令属于冗余内容，在它掩盖下一条真实违规之前删除。
