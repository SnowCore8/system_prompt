# 文档注释

## 1. 文档注释

- 在每个公开边界记录参数、返回值、错误、副作用与不变量；变更契约即变更 API，文档注释随签名同步更新。
- 记录签名无法承载的内容：单位（毫秒还是秒）、范围（包含还是不包含）、可空性（缺失还是为空）、所有权（借用还是拥有）。
- 摘要一句说清行为，不重复类型提示；项目使用 Google 风格时补 `Args:` 与 `Raises:` 小节。
- 文档注释放在声明上方，使用工具的语法；代码示例属于可执行的文档，支持 doctest 的必须执行并产生所述输出。
- 与当前代码矛盾的文档注释是缺陷，在同一次变更中修复或删除，并搜索仍承诺旧行为的调用方注释。
