# 标记

## 1. 标记

- `TODO` 表示有负责人的计划内工作，必须带负责人、动作与 issue 或移除触发条件：`// TODO(maria): drop the shim after v2 ships (#512).`
- `FIXME` 与 `HACK` 表示已知缺陷或捷径，必须带错误行为、负责人与移除触发条件。
- `NOTE` 与 `WARNING` 表示上下文或隐患，按条件、后果、必需动作的顺序说明；未指明动作的警告无法让读者行动。
- 标记遵循项目的拼写，全部使用同一种写法；裸的“以后修复”不属于标记，属于遗漏。
- issue 引用使用平台可解析的语法：`#123`、`owner/repo#123` 或完整链接。
- 标记被解决时在同一次变更中删除；长期不动的标记是虚假信号，需要要么完成、要么清理。
