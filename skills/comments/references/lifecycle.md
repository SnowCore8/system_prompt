# comments 生命周期契约

本文件是 `comments` 的阶段契约：阶段职责、门禁证据、交接与升级、裁剪与度量。阶段与门禁编号由 `project-lifecycle` 裁定；本文件只写本 skill 在各阶段的输入、活动、输出与证据形态。

## 阶段职责

| 阶段 | 输入 | 活动 | 产出与证据 |
|---|---|---|---|
| S0 受理 | 注释类请求：写注释、审查 diff 中的注释、修复过时注释 | 复述对象与范围，判断是否触及公开契约或法律声明头 | 受理记录、风险级别 R0/R1/R2 |
| S1 需求 | 现有注释、文档工具配置、仓库声明的语言 | 盘点过时、误导与缺失的注释，列出待决项 | 注释现状清单、公开契约清单草案 |
| S2 设计 | 接口契约与文档工具链 | 确定公开契约的文档注释要求、自然语言、标记与工具指令策略 | 注释策略、文档工具配置、语言声明 |
| S3 构建 | G2 通过的注释策略 | 按类型写注释，契约随签名同步；标记带负责人与触发条件 | diff 中的注释、标记清单、弃用声明 |
| S4 验证 | 增量与文档工具配置 | 核对注释与代码一致，运行文档构建、doctest 与注释 lint | 构建输出、doctest 结果、过时注释清单 |
| S5 发布 | 验证证据 | 核对弃用声明、生成标记与发布说明的衔接 | 弃用与移除窗口记录、发布说明 |
| S6 运维 | 事故与使用反馈 | 依据注释误导或缺失导致的故障记录，归入注释修复待办 | 故障中的注释缺陷记录 |
| S7 收尾 | 全程记录 | 复盘注释策略是否被工具强制，遗留的过时注释移交 | 复盘记录、遗留项清单 |

## 门禁证据

G0：请求复述、授权依据、风险级别与停止条件；触及法律声明头时按 R2 处理。
G1：注释现状清单与公开契约清单草案；未盘点的注释不得当作已确认事实。
G2：注释策略、文档工具配置、仓库语言声明、公开契约清单；策略缺失时 Hold。
G3：注释 diff、标记的负责人与触发条件、弃用声明与替代项；裸标记与被注释掉的代码阻断合并。
G4：文档构建与 doctest 输出、注释 lint 结果、过时注释清单；行为变更未同步注释时 Recycle。
G5：弃用与移除窗口记录、生成标记完整、发布说明衔接；缺失时 Hold。
G6/G7：故障中的注释缺陷记录与复盘记录；只作记录，不作为发布前门禁的替代。

## 交接与升级

上游交接：`api-data` 提供公开契约；`naming` 提供标识符；`code-style` 提供注释的缩进与行宽配置。下游交接：生成的 API 文档交 `documentation` 发布；弃用时机与移除窗口交 `release-operations`；机密扫描交 `security-compliance`；注释 lint 交 `testing-quality` 接入 CI。

升级条件：注释中出现凭据或个人数据时立即停止、保留证据并报告；公开符号的契约变更退回 G2 重新确认。停止条件：调查结束前不清理疑似泄露的注释；无授权不修改第三方引入代码中的上游注释。

## 裁剪与度量

裁剪：R0 只保留受理、一次验证与交付记录；R1 使用精简计划与 G4 非作者审查；R2 需独立审查，涉及法律声明头时需人工批准。注释策略与语言声明不因裁剪而省略。

度量：过时注释数、注释 lint 违规数、文档构建失败次数按基线比较趋势；指标恶化时先查根因，不调整阈值。度量不替代门禁判断。
