# 被注释掉的代码

## 1. 被注释掉的代码

- 删除被注释掉的代码，历史由版本控制保留；留在源码里的死代码会腐化、掩盖废弃 API 并干扰搜索。
- 临时禁用必须带负责人、工单与到期时间，到期后要么恢复、要么删除。
- 被注释掉的调试输出同样删除；需要调试信息时使用可配置级别的 logger。
- 发现被注释掉的代码中嵌有凭据的，立即停止操作、保留证据并报告，不先删除。
- 注释属于公开内容：它们随源码、生成的文档、调试符号与包一起发布；不存放凭据、令牌、密钥或连接串。
- 示例不使用真实姓名、邮箱、电话、地址或生产 URL；用 `example.test.invalid` 与占位标识符。
- 不在公开或引入的注释中描述内部网络、服务拓扑或主机名；安全事件细节脱敏，指向私有跟踪系统而非粘贴报告。
