# 行内与块注释

## 1. 行内与块注释

- 解释不显而易见的原因，不复述代码已经说明的行为；`// increment i` 这类注释先考虑重命名标识符或改进代码。
- 行内注释放在所解释行的上方或旁边，缩进与该行相同；块注释放在所解释代码块之前，块与其描述的代码之间空一行。
- 每条注释一个想法，写完整句子，句首大写并带句末标点；描述用现在时陈述行为，指令用祈使式。
- 记录不显而易见的内容：外部约束、变通做法、unsafe 不变量、令人意外的边界情况与实测性能界限；跳过语言教程与熟悉的内容。
- 需要注释解释形状的代码块属于待提取的函数；注释长于一段的设计说明移入文档并链接，不复制进代码。
- 密度取决于意外程度而非行数：每行都有注释的文件与完全没有注释的文件一样难读。
- 行尾注释只用于简短的、行内的说明；避免 ASCII 艺术、横幅分隔线与对齐填充。

| 好 | 差 | 原因 |
|---|---|---|
| `# Retry once: the gateway resets idle connections.` | `# increment i` | 前者说明代码未表达的原因 |
| `/* The vendor caps a batch at 500 items. */` | 装饰边框包裹的整段描述 | 块注释说明外部约束 |
| 完整句子，一种自然语言 | 中英混写的外语注释 | 单一语言规则保护审查效率 |
