# 生成代码与第三方引入代码

## 1. 生成代码与第三方引入代码

生成代码与第三方引入代码归生成器或上游项目所有，不归本项目的风格规则所有；两者都通过修改其来源而变化。
目录声明、只读规则、上游来源与补丁记录由 `project-structure` 裁定；本文件只规定格式化与 lint 一侧的执行方法。

- 排除规则由 `project-structure` 裁定（生成目录与第三方代码排除于格式化与风格规则）；排除项写入可审查的工具配置，并注明生成器或上游项目。
- 生成输出带机器可检测的头部，写明生成器、版本与命令；排除按该标记与目录声明实施，不依赖手工清单单列文件。
- 不得手工编辑生成代码；生成 diff 不得混入手工编辑，漂移时回到生成器修复（重生成的完整规则见 `project-structure`）。
- CI 重新生成并对漂移失败；生成器自带校验模式时使用该模式，否则以 `git diff --exit-code` 比较工作树与已提交输出。
- 第三方引入代码经一个边界导入，升级或替换只动一个文件；同一边界内保留原风格与注释，不按本 skill 的规则改造（见 `project-structure`）。
- 区分生成源码与构建输出：生成的客户端与锁文件提交，`dist/`、缓存与编译产物忽略；忽略与重建规则由 `project-structure` 裁定。
