# 生成代码与第三方引入代码

## 1. 生成代码与第三方引入代码

生成代码与第三方引入代码归生成器或上游项目所有，不归本项目的风格规则所有；两者都通过修改其来源而变化。

- 生成输出放已声明的目录或文件名模式，带机器可检测的头部，写明生成器、版本与命令；依赖生态标记而非手工清单排除。
- 不得手工编辑生成代码：修改 schema、模板或生成器调用后重新生成，输入与输出一并提交；手工编辑会在下次生成时无声消失。
- CI 重新生成并对漂移失败；生成器自带校验模式时使用该模式，否则以 `git diff --exit-code` 比较工作树与已提交输出。
- 第三方引入代码放隔离目录，附上游来源、版本或提交、许可证文本与引入理由；经一个边界导入，升级或替换只动一个文件。
- 生成代码与第三方引入代码排除于 formatter、linter 与风格审查之外，排除项写入可审查的工具配置，并注明生成器或上游项目。
- 区分生成源码与构建输出：生成的客户端与锁文件提交，`dist/`、缓存与编译产物忽略并在流水线中重建。
