# 代码异味清单与安全手法目录

本文件为可判定的目录：异味列明触发阈值，手法列明等价变换与反向手法。判定何时重构、选择何种手法时，智能体应当
查阅本表。阈值属于默认值；项目约定与事实属于输入，本 skill 的规则优先，项目约定仅在本 skill 未规定时补充。

## 代码异味清单

| 异味 | 触发阈值 | 重构方向 |
|---|---|---|
| 重复代码 | 三处及以上逻辑相同或近似 | 提取方法或类，统一至一个权威来源 |
| 长函数 | 单函数超过约 40 行，或承担多项不相关职责 | 按职责提取方法 |
| 长参数列表 | 参数超过 4 个，且多个参数总是同时出现 | 引入参数对象 |
| 数据泥团 | 三个及以上字段总是同时传递或同时变更 | 提取类或参数对象 |
| 开关语句 | 同一开关散落于多处，新增分支需修改多处 | 以多态或策略替换，或集中至一处 |

## 安全手法目录

| 手法 | 等价变换 | 反向手法 | 适用场景 |
|---|---|---|---|
| 提取方法 | 将一段逻辑移入新方法并替换调用点 | 内联方法 | 长函数、重复代码 |
| 提取类 | 将一组相关字段与方法移入新类 | 内联类 | 数据泥团、过大的类 |
| 内联方法或类 | 将仅被一处使用的成员展开回调用点 | 提取 | 过度设计的间接层 |
| 移动方法或字段 | 将成员移至更合适的类 | 移回 | 数据泥团、散弹式修改 |
| 重命名 | 仅改标识符，不变更行为 | 重命名 | 名不副实；命名规则由 `naming-conventions` skill 管辖 |
| 替换魔法数 | 以命名常量替换无说明的字面量 | 还原字面量 | 无处名的魔法数 |

## 手法与提交的对应

- 每一项手法一步、一次提交；智能体应当先实施机械安全的手法，后实施引入风险的结构调整。
- 语言或 IDE 的自动重构优先；其次为手工但逐引用核对，手工重命名必须核对测试、文档、配置与序列化字段。
- 手法执行后运行测试套件并保持通过；任何一步转为失败的，应当先用反向手法回退，再查明原因。
