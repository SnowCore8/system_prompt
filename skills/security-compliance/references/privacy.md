# 安全与合规：PII 与隐私

个人数据的风险在于收集即承担义务：保留、删除、跨境与处理者条款都从收集开始。控制放在收集之前，比在泄露之后补救有效得多。

## 1. PII 与隐私
- 生产流量到达之前，每个数据元素在数据清单中登记类别、用途、系统、保留期限、接收方与区域。
- 隐藏于日志、URL、分析事件或错误报告中的收集同样算收集，须经同一登记。
- 无书面用途的字段不得存在；同意、合法依据或合同要求按适用法律逐一确认。

## 2. 最小化与保留

- 不需要身份时使用假名化或聚合；日志、事件名称与测试夹具不得出现 PII。
- 每个保留期限配置可执行的删除路径；开发与测试环境不得使用生产个人数据。
- 数据主体请求按已发布的运行手册处理，覆盖日志、备份与处理者处副本；处理者删除条款写入合同。

## 3. 变更审查

- 新增处理者、跨境传输或同意机制变更时实施隐私审查；审查结论不足以裁定的移交法务；审查未完成不得上线。
- 事件 schema、分析字段与遥测的变更纳入同一审查；"先加一个字段，以后再审查"不构成例外。
- 疑似隐私泄露按 SEC-6 处理：停止操作、保留证据、立即报告。
