# 安全与合规：许可证合规

许可证义务随分发触发：把依赖编译进制品或随制品分发，即承担其条款义务。分类在依赖进入代码库之前完成，随发布出具清单与声明。

## 1. 许可证合规
- 依 SPDX 标识符把依赖归入允许、审查与禁止三类；未识别的许可证在人工识别之前一律按禁止处理。
- 禁止类（无许可证、含强传染条款的 copyleft）不得引入；审查类需记录书面例外、负责人与到期日。
- 传递依赖与直接依赖同等检查；门禁在依赖审查或构建中强制执行，不得只靠人工记忆。

## 2. 入站与出站

- 入站：记录每个组件的许可证、版本与用途，随依赖变更更新；产品上下文与分发方式变化时重新评估。
- 出站：依最终制品实际包含的组件生成声明文件与署名列表，核对入站与出站条款兼容。
- 第三方代码保留其许可证头与声明；修改第三方代码前确认修改与再分发条款允许。

## 3. 例外管理

- 每个例外写明组件、条款、缺口、补偿控制、负责人与到期日；到期未复审自动成为未处理发现项。
- 法务问题移交法务并记录答复；本 skill 的默认值不构成法律结论。
