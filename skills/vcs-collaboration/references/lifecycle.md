# 版本控制与并行协作生命周期契约

本文件回答：分支、审查、保护、所有权与工作树工作在哪一阶段产生哪一类证据，证据不足时停在哪里。阶段与门禁
的编号与判定语义由 `project-lifecycle` 裁定；本文件把该框架落到 PR、合并、规则集、CODEOWNERS 与工作树，
不重述门禁定义。维度规则见对应维度文件。

## 阶段职责

| 阶段 | 输入 | 活动 | 输出 | 门禁 |
|---|---|---|---|---|
| S0 受理 | 请求对象与仓库状态 | 判定触碰协作的哪一部分，记录风险级别与停止条件 | 受理结论 | G0 |
| S1 需求 | 团队规模、发布路径、并行任务 | 比较分支模型与协作选项，确认并行边界 | 模型取舍、任务清单 | G1 |
| S2 设计 | 范围与验收、发布路径 | 选定模型与合并方式、审查级别、保护集合、所有权映射，登记工作树 | 分支策略、规则集配置、任务板 | G2 |
| S3 构建 | 已通过 G2 的计划 | 按模型建分支与工作树，准备 PR，分派审查，按依赖集成 | PR、合并提交、集成记录 | G3 |
| S4 验证 | 增量与审查线程 | 核对批准有效性、必需校验与阻塞解决，在集成结果上重新验证 | 审查与验证结论 | G4 |
| S5 发布 | G4 结论与逐次同意 | 保护发布分支与标签，热修复经审查并向前移植 | 标签规则、合并证据 | G5 |
| S6 运维 | 分支列表、绕过记录 | 修复保护漂移与所有权缺口，处置协作事故 | 漂移修复、事故结论 | G6 |
| S7 收尾 | 工作树清单与复盘输入 | 清理已合并分支与遗留工作树，复盘协作失效 | 清理记录、复盘结论 | G7 |

S4 只验证 S2 已确定的模型与保护，不在验证阶段重新设计流程；发现设计缺陷按 Recycle 回到 S2 修订。

## 门禁证据

| 门禁 | 证据形态 | 复核者 | 不可接受的证据 |
|---|---|---|---|
| G2 | 分支策略文件与平台设置；每类合并方式；审查级别表；规则集配置草案；CODEOWNERS 草案；工作树任务板 | 项目负责人与平台管理员 | 只有口头约定，无策略文件或设置 |
| G3 | PR 描述与自审；必需校验在合并结果上的输出；工作树基线 SHA 与集成记录 | 提交者自检；R1 起加独立审查 | 校验只跑在作者副本；未登记的写入 |
| G4 | 归属团队批准记录；阻塞评论的解决；批准未过期；集成结果验证输出 | 独立审查者；R2 加安全结论 | 不读 diff 的批准；过期批准 |
| G5 | 发布分支与标签保护证据；热修复 PR 与向前移植记录 | 运营与发布批准人 | 移动发布标签；绕过队列合入 |

- R0：单文件措辞修正，可把 G2 与 G4 记录合并，仍须在合并结果上通过必需校验。
- R1：至少一名非作者审查；保护与所有权变更须经维护者复核。
- R2：跨团队契约、权限或保护变更、历史重写，G4 需要独立审查，G5 需要逐次同意与回滚记录。
- 例外（如体量超标、无第二人的自审）必须有所有者、范围与到期条件，并写入策略文件或门禁记录。
- 证据链接指向具体 PR、工作流运行、规则集或任务板条目，不指向口头承诺。

## 交接与升级

交接：

- 交 `testing-quality`：必需校验清单与合并前门禁，作为 CI 运行。
- 交 `release-operations`：发布分支、标签规则与热修复路径。
- 交 `documentation`：贡献者指南与分支模型的更新点。
- 交 `naming`：分支、提交与标签命名格式的裁决。
- 交 `security-compliance`：绕过记录的审计要求与 fork 工作流的令牌边界。
- 交 `project-structure`：生成路径与第三方引入路径的审查豁免范围。

升级：

- 审查或校验证据无法补齐：Hold，不得合并。
- 需要重写受保护分支、移动发布标签或绕过保护：升级用户逐次同意，不得自行实施。
- 分支模型与发布路径不符：Recycle 到 S2 重新选择并补齐证据。
- 工作树写者失联或存在脏状态：先隔离与保全，再请求决策，不得直接移除。
- 强制规则之间冲突：报告用户裁决，并把所选约定记录于策略文件。

停止条件：

- 未取得逐次明确同意时不得推送保护或共享分支、删除远端分支或重写已发布历史。
- 发现疑似凭据或个人数据进入 diff、评论或 CI 日志时按 SEC 条款停止并报告。
- 必需校验在合并结果上失败时停止合并，不得以作者副本的通过替代。

## 裁剪与度量

裁剪：

- R0：一条受理兼计划记录；保留合并结果上的校验输出。
- R1：完整策略文件但可精简；独立审查一名。
- R2：不得裁剪；策略、审查、保护与回滚演练四项证据必须同时存在。

度量：

| 指标 | 定义 | 用途 |
|---|---|---|
| PR 前置时间 | 从开启到合入的中位时长 | 发现审查阻塞与批量过大 |
| PR 体量 | 可审查 diff 行数分布 | 校准体量预算 |
| 审查周转 | 请求审查到完成审查的时长 | 发现审查瓶颈 |
| 绕过次数 | 保护绕过记录的次数与原因 | 判断例外是否失控 |
| 所有权缺口 | 无具名所有者的可合并路径数 | 发现孤儿路径 |
| 集成返工率 | 因集成失败而退回写者的任务比例 | 校准依赖拆分与隔离 |

审查节奏：每个发布周期复核一次度量与策略文件；异常先查流程根因，再调整阈值。
