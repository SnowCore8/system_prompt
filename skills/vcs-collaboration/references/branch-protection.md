# 分支保护与规则集

## 1. 分支保护
- 受保护分支默认拒绝强制推送与删除，要求 PR 与批准，并在合并结果上要求必需校验通过。
- 平台提供规则集时优先使用：过期批准失效、要求最近一次推送的批准、要求代码所有者审查与对话解决、必需校验设为合并条件。
- 规则集与旧式保护叠加时最严格者生效；签名提交要求来自平台或组织策略，本地钩子仅作早期提示。
- 合并量大时启用合并队列：必需工作流同时响应 pull_request 与 merge_group，队列失败修复后重新入队，不得重试同一结果。
- 发布标签同样受保护：已发布的标签不得移动、删除或重建，因为已发布制品指向它。

## 2. 绕过与例外

- 绕过列表只保留紧急通道；每次绕过记录操作者、原因、被绕过的规则与合并后审查。
- 无记录的绕过按事故处理；“就这一次”直接推送主干默认拒绝。
- 事故或冻结期间禁用自动合并；恢复前复核待合并队列。
- 工作流、复合 action 与保护配置的变更由平台团队审查；来自 fork 的构建只获得只读令牌且无仓库机密。
