# CODEOWNERS 与代码所有权

## 1. 所有权映射

- 每条可合并路径都有具名所有者；回退所有者是平台或仓库维护者团队，不是下一个编辑该路径的人。
- 只有通配回退条目的，仍可合并，但必须在治理文件中记录该单点并定期复核。
- 生成路径归生成器所有者，第三方引入路径归引入者；审查的是生成器输入与重新生成命令。
- 覆盖缺口属于带期限的缺陷：在下一次变更之前修复，不得无限期挂起。

## 2. 所有权变更

- 授予或移除所有权的修改需要维护者审查，并在独立请求中合入。
- 存在第二人时，所有者不得批准扩大自身权限的变更；单人仓库以自审记录与必需 CI 替代。
- 所有权映射变更与代码同等接受审查；批准路由的细节由 `project-structure` 的治理规则裁定。
