# 文档生命周期契约

本文件规定本 skill 在 S0–S7 中的职责、门禁证据、交接与升级、裁剪与度量。页面结构细节见五个维度文件；
阶段与门禁编号由生命周期治理模型裁定，本 skill 主责 S3 的随变更文档与 S4 的一致性结论。

## 阶段职责

| 阶段 | 输入 | 活动 | 输出 |
|---|---|---|---|
| S0 受理 | 请求与既有文档结构 | 判断涉及哪些页面与事实，确认变更范围 | 受影响页面清单 |
| S1 需求 | 问题、用户与结果指标 | 确定读者与文档缺口，划定文档集范围 | 读者定义、缺口清单 |
| S2 设计 | 范围与设计决策 | 为 ADR 与设计文档提供模板，规划文档任务 | ADR 骨架、文档任务 |
| S3 构建 | 增量与设计文档 | 随增量更新页面，维持单一归属与当前事实 | 文档 diff |
| S4 验证 | 文档 diff 与增量 | 核对文档与实现一致，运行构建、链接与示例校验 | 校验输出、一致性结论 |
| S5 发布 | 发布候选与变更列表 | 交付变更日志与发布说明，标明升级动作 | 分组条目、迁移指南链接 |
| S6 运维 | 告警、事故与用户反馈 | 更新运行手册与故障排查页，事故后补复盘 | 运行手册更新、复盘记录 |
| S7 收尾 | 收尾输入与页面清单 | 写收尾报告，归档过时页面并留重定向 | 收尾报告、归档状态 |

S3 与 S4 循环推进：文档与代码同批提交，校验失败退回 S3 修复，不得把校验留到发布前。

## 门禁证据

| 门禁 | 证据形态 | 失效条件 |
|---|---|---|
| G1 | 读者与问题说明、缺口清单与负责人 | 读者未定、缺口无人负责 |
| G4 | 构建、链接与示例校验输出，文档与实现的逐项对照 | 校验未运行，或行为变化缺文档 diff |
| G5 | 按版本分组的变更日志、含升级动作的发布说明 | 升级动作缺失、条目与版本不符 |
| G7 | 收尾报告、归档与重定向记录 | 过时页面未归档、重定向失效 |

证据必须来自实际运行输出；承诺"稍后补文档"不构成证据。

## 交接与升级

- 从 `requirements-engineering` 接收问题与读者；从 `architecture-design` 接收 ADR 与边界；从 `api-data` 接收契约用于生成参考页。
- 发布事实（版本、批准、上线与回滚）由 `release-operations` 提供，本 skill 只负责呈现；文档校验接入 CI 的位置归 `testing-quality`。
- 升级：事实的权威归属有争议时交 `project-lifecycle` 裁定；发布事实与文档冲突时以 `release-operations` 为准；缺少权威来源时停止编写并报告。
- 停止：批量删除或归档未取得同意、页面归属无法确定、或校验持续失败时停止，报告受阻项与已完成项。

## 裁剪与度量

| 级别 | 裁剪 | 不可裁剪项 |
|---|---|---|
| R0 | 措辞修正与断链修复只改受影响页面，不建新模板 | 链接校验与当前事实表述 |
| R1 | 新页面用既有模板，文档 diff 与代码同批提交 | G4 的一致性结论 |
| R2 | 完整文档集规划，新模板与生成器变更须审查 | 发布说明的升级动作与归档记录 |

度量：以死链数、过时页面数、文档与实现漂移数为准；数值上升时先查归属与触发条件，不得放宽校验。
