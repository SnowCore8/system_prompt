# 文档：运行手册与变更记录

运行手册服务值班者，变更记录服务用户：前者要的是立即可执行的步骤，后者要的是"这次发布我需要做什么"。两者都以告警或版本为界，不写散文。

## 1. 运行手册

- 每本手册对应一个告警或故障：触发条件、影响、首个动作、步骤、验证、回滚与升级路径。
- 步骤按执行顺序编号，每条命令给出预期输出；回滚路径与止损动作不得省略。
- 手册随事故复盘更新；无法演练的步骤标注"未演练"，不冒充已验证。

## 2. 变更日志与发布说明

- 变更日志按版本与日期分组，条目写用户可见的变化与所需动作，不重复 git log。
- 破坏性变更单独分组并链接迁移指南；弃用写明替代方案与移除版本。
- 发布说明由变更日志条目生成，补充升级动作、回滚方式与已知问题。

## 3. 迁移指南

- 写明受影响受众、时间线、字段映射、步骤、验证与回滚；每个映射给出旧值到新值的示例。
- 指南与本次发布同批交付；缺少迁移路径的破坏性变更不得发布。
