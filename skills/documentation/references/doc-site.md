# 文档：文档站与同步校验

文档站是文档的交付界面，同步是文档的生命线：内容在仓库与站点之间、代码与页面之间保持一致，靠生成器锁定与 CI 校验保证。

## 1. 文档站与同步校验
- 采用单一锁定版本的生成器；内容以可移植的 Markdown 存于仓库，站点为生成产物。
- 导航按读者任务组织：核心页面三次点击内可达；新页面接入导航并更新文档索引。
- 页面载明适用版本、平台与受众；公开页面不含内部地址、机密或员工数据。

## 2. 同步与权威归属

- 每项事实只有一个权威页面，其余位置链接；检索发现重复答案时合并而不是新增。
- 行为变更与文档 diff 在同一次变更中落地；默认分支不得描述旧行为。
- 每个页面写明负责人与审查触发条件；无人负责的页面无人修复。

## 3. 校验与归档

- 构建、链接、锚点与示例校验接入 CI；死链与不可运行的示例在同一次变更中修复。
- 图表与截图随 UI 重新生成并标注范围；生成文档修改生成器或源注释后重新生成，不得手工编辑产物。
- 过时页面归档或重定向并留墓碑页；删除前核查入站引用。
