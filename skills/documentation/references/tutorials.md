# 文档：教程与操作指南

教程与操作指南都是"通往结果的道路"，区别在读者：教程面向学习者，按步骤完成一个示例；操作指南面向实践者，快速到达一个目标。

## 1. 教程与操作指南
- 开头写明预期结果与前提，随后是编号步骤，结尾给出最终结果与下一步。
- 每一步可独立验证：读者能判断自己是否做对；步骤顺序即读者执行顺序。
- 教程只教受支持的路径；变体与替代方案放指南或参考，不打断主线。

## 2. 操作指南

- 每篇指南只回答一个任务：目标、前提、步骤、验证与常见失败，五项齐备。
- 受支持的路径放在最前并标明；其余选项列在后方并注明取舍。
- 每个命令写明工作目录与变量，能复制后直接运行；截图不作为命令的替代。

## 3. 参考与解释

- 参考页穷尽而精确地列出选项、默认值与约束，并载明适用版本；可生成的参考页不手写。
- 解释页回答"为什么如此运作"，承载模型与权衡；读者只需答案时不要送进解释页。
