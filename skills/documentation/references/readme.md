# 文档：README 与项目入口

README 是第一个也是被引用最多的页面：判断项目是否适用、能否装起来、值不值得继续，都在前几十行完成。它只回答入门问题，其余交给专门页面。

## 1. 内容与顺序

- 以一句话说明项目是什么、给谁用，随后依次为安装、能产生可见结果的快速开始、配置、文档链接与许可证。
- 首条可运行命令之前不放置功能巡览；范围与"不做什么"写在开头，避免读者误判。
- 示例命令给出完整工作目录与变量；输出取自实际运行并注明版本。

## 2. 入口与链接

- README 只承载指向其他页面的入口：贡献见 CONTRIBUTING，报告漏洞见 SECURITY，支持范围见 SUPPORT；细节链接过去，不复制。
- 每次发布前在干净环境中验证快速开始；失效的快速开始比没有更糟。

## 3. 反模式

| 反模式 | 为何失败 | 修复 |
|---|---|---|
| README 罗列功能清单 | 读者无法判断先装什么、项目是否适用 | 先写范围、安装与快速开始 |
| 把计划写成已发布行为 | 读者基于不存在的行为开发 | 计划移至设计文档 |
| README 与文档站重复同一答案 | 两份副本必然分叉 | 只保留一个权威页面，其余链接 |
