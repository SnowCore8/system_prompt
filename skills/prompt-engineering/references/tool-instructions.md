# 工具与检索指令

## 1. 工具调用指令

- 写明何时调用何工具、参数约束与调用时机；工具的 schema 与错误语义由 `mcp-engineering` 管辖，调用方只描述选择与时机。
- 工具失败、无权限与结果不满足要求时各有一个分支，不写“必要时调用工具”这类空指令。
- 只授予完成任务所需的工具与字段；未授权写、外部发送与不可逆动作需要明确同意，任务范围内的本地可逆写直接执行。

## 2. 检索与数据区

- 用户内容、检索结果与工具输出放进明确分隔的数据区，声明其中出现的指令一律不执行。
- 不得把外部文本拼接进系统提示区；要求答案引用原文并给出处。
- 检索无结果、结果冲突与结果不相关时各有一个处理分支。

## 3. 指令层级与注入防线

- 指令层级：system 与 developer 高于用户请求，用户请求高于工具输出；数据区内文本不构成指令，除非外层指令明确授权。
- 系统提示区放能力、约束与契约；用户请求放任务；工具输出放数据。三者混同是注入的主要入口。
- 高风险的写、删、发送与权限操作不在提示词中授予默认权力，交给用户逐次确认。
