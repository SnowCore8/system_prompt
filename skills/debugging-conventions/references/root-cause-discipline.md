# 根因治理与方案验证（CH-4、ME-12）

CH-4 沿用原用户全局约束的编号；ME-12 见 `rules/global-user-constraints.md`。

## CH-4 根因治理

补丁无法修复根因的，应当重构，不得逐层叠加补丁。同一问题的第二个补丁仍然失败的，应当停止，先查明根因；根因
属于结构性的，应当重构。重构超出授权的，应当说明根因、范围与替代方案，再请求确认。补丁将掩盖根因，使后续改动
成本持续上升。

## ME-12 方案验证

ME-12 是 `rules/global-user-constraints.md` 的常驻条款，本文不复制其正文；两者冲突时以该文件为准。

ME-12 与 CH-4 的关系：3 个版本应当针对不同根因假设或不同实现路径，不得把 3 个版本做成 3 次叠补丁。
