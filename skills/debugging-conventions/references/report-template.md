# 缺陷报告模板

本文件是可复制的缺陷报告骨架。复制后删掉不适用的段落，不保留空占位。字段必须填到能判定为止：缺「期望与实际」
或复现步骤的报告退回补齐。

## 最小缺陷报告

```text
标题：<一句话：什么在什么条件下出了什么错>

环境
- 语言与运行时：<版本>
- 操作系统与平台：<版本>
- 依赖：<锁定版本或清单>
- 配置：<与默认值的差异>
- 数据规模：<记录条数、文件大小等>

复现步骤
1. <第一步>
2. <第二步>
3. <第三步>

期望结果
<应发生什么>

实际结果
<实际发生了什么，附错误信息或日志摘录>
```

## 复现不了时的报告

```text
结论：无法复现

已尝试的环境与步骤
- <环境组合一与步骤>
- <环境组合二与步骤>

观察到的现象
<每次尝试的期望与实际>

需要补充的信息
- <还缺什么才能复现>
```

## 最小复现的裁剪

- 从完整场景出发，逐步删掉与缺陷无关的输入、依赖与数据。
- 每删一步都重跑，确认缺陷仍触发；删到再删一步就不触发为止。
- 保留触发条件的关键数据样本，脱敏后附上，不附真实机密或个人信息。
