# 提示词规范生命周期契约

本文件说明提示词在阶段之间如何交付与验收：目标如何变成判定标准、契约与评测如何成为门禁证据、改动何时必须
回到评测，以及按风险级别如何裁剪。

## 阶段职责

| 阶段 | 输入 | 活动 | 输出 | 门禁 |
|---|---|---|---|---|
| S1 探索 | 目标、用户任务、失败样例 | 拆分评价性词语；写失败定义；列输入输出字段 | 目标句、失败定义、判定标准 | G1 |
| S2 计划 | 类型候选、模型清单、结果消费方 | 选类型与职责边界；定输出契约与示例计划；建评测集与基线 | schema 或精确样例、示例计划、评测集与基线 | G2 |
| S3 构建 | 契约、模板、调用点 | 写骨架并接入调用点；标注模型与采样参数；替换动态输入位置 | 渲染后的提示词、版本标记 | G3 |
| S4 验证 | 冻结评测集、提示词版本 | 单变量回归；运行断言；记录成本与延迟；跑对抗样本 | 评测输出、对比表、退化结论 | G4 |

阶段边界：S1 不写规则；S2 不调参；S3 不改契约字段（要改则退回 S2）；S4 只运行与记录，不得在同一次评测中
顺手改提示词，否则指标无法归因。

## 门禁证据

- G1 立项。证据为目标句、失败定义、至少一个失败样例与输入输出字段清单。“效果更好”不构成判定标准。
- G2 计划。证据为类型与职责边界、输出契约（schema 或精确样例）、示例计划（正例、边界、反例）、评测集分层与
  基线（指标、成本、延迟）、目标模型与采样参数。
- G4 验证。证据为断言结果、与基线的指标对比、单变量变更说明、对抗样本（注入、越界、空输入、超长输入）结果、
  成本与延迟，以及旧版本可回滚的标记。任一项缺失即未通过。

证据与决定：

| 情形 | 决定 | 处理 |
|---|---|---|
| 核心断言零失败，指标不低于基线，变更单变量 | Go | 可上线并保留旧版本 |
| 指标持平但成本或延迟上升且未解释 | Hold | 补取舍说明与负责人，再决定是否上线 |
| 指标下降且归因不明 | Recycle | 回到 S2 检查契约与示例 |
| 提示词、模型与参数同批变更 | Recycle | 拆为单变量，逐项重跑后再比较 |
| 注入样本能改变行为 | No-Go | 修正数据边界；风险面交 `security-compliance-conventions` |

## 交接与升级

上游交入：

- `project-lifecycle-governance` 给出阶段、风险级别与门禁要求；评测结果按该处定义的证据标准提交。
- 平台与模型提供方给出上下文长度、工具 schema 与结构化输出能力；本 skill 不假设未提供的能力。
- 领域 skill 给出术语、字段与格式的权威定义；提示词只引用，不复制。

下游交出：

- 需要每会话常驻的内容，交 `system-prompt-authoring` 决定去留与写法。
- 只在部分任务使用的规范，交 `skill-authoring` 作为按需加载的包维护。
- 回归用例与断言交 `testing-and-quality-conventions` 纳入 CI；版本与回滚路径交
  `release-operations-conventions`。
- 注入、越权与隐私的防线与例外，交 `security-compliance-conventions` 裁定。

升级条件：

- 模型或采样参数变更：视为行为变更，重跑完整评测，不得沿用旧基线结论。
- 评测集污染：样本被用作 few-shot 示例或反复调参依据时，重建评测集再判断。
- 契约与下游不一致：解析器读到的字段与 schema 不符，先修契约，再修提示词。
- 共享规则无权威处：两处提示词各自定义同一格式，升级到对应领域 skill 或由用户裁决。

停止条件：

- 目标仍含无法拆分的评价性词语时停止编写，先取得可观察标准。
- 没有冻结评测集时停止调参，先建集合与基线。
- 不可信输入无法与指令分隔时停止，改为隔离数据区或拒答。
- 平台不支持结构化输出时停止假装有 schema，改用精确样例并在交付中标注兜底。

## 裁剪与度量

按风险裁剪：

| 级别 | 典型改动 | 必做 | 可省略 |
|---|---|---|---|
| R0 | 措辞、示例文案微调，不改契约与变量 | 冒烟用例、渲染检查 | 完整回归与成本对比 |
| R1 | 新增规则或示例、调整提示词结构 | 断言回归、指标与成本对比、单变量说明 | 对抗样本扩充 |
| R2 | 改输出契约、模型、采样参数、工具集合 | 完整评测、对抗样本、独立审查、回滚演练 | 无 |

度量：

| 指标 | 计算 | 用途 |
|---|---|---|
| 断言通过率 | 评测集中通过断言的样本比例 | 判断是否可用 |
| 覆盖层数 | 正常、边界、非法、注入、超长、空输入中有样本的层数 | 判断盲区 |
| 单变量变更占比 | 单变量提交占全部提示词提交的比例 | 判断归因是否可能 |
| 成本与延迟 | 每次调用的 token 成本与 P95 延迟 | 判断取舍是否成立 |
| 逃逸缺陷 | 上线后用户报告的行为偏差数 | 判断评测是否贴近真实输入 |

度量纪律：不以单一指标判断改善，不以一次演示替代评测；指标改善而成本暴涨时须显式取舍并记录。指标恶化先查
数据定义与评测集，不得先改目标或缩小统计范围。
