# 项目结构生命周期契约

本文件规定本 skill 在 S0–S7 中的职责、门禁证据、交接与升级、裁剪与度量。目录与门禁细节见五个维度文件；
阶段与门禁编号由生命周期治理模型裁定，本 skill 主责 S2 的结构计划与 S4 的边界复核。

## 阶段职责

| 阶段 | 输入 | 活动 | 输出 |
|---|---|---|---|
| S0 受理 | 请求与仓库现状 | 判断结构调整涉及哪些目录、包与依赖 | 受影响范围与风险级别 |
| S1 需求 | 需求与约束 | 判断结构是否承载需求风险，比较项目形态选项 | 结构选项与主要风险 |
| S2 设计 | 架构裁定与项目事实 | 把边界映射到目录、包与工作区，定义公开面与门禁 | 目录映射表、包清单、门禁方案 |
| S3 构建 | 映射与设计 | 落地新增或移动目录，同步导入、测试与文档 | 结构调整 diff、构建输出 |
| S4 验证 | 增量与提交记录 | 复跑导入检查与构建图门禁，核对所有者映射 | 门禁输出、例外记录 |
| S5 发布 | 验证结论与发布候选 | 核对打包入口与制品清单，确认发布含所需目录 | 包导出与制品清单 |
| S6 运维 | 运行中的结构调整需求 | 评估补丁与热修对结构的影响，控制边界漂移 | 结构影响评估 |
| S7 收尾 | 归档或退役输入 | 归档仓库或退役目录，清点目录与依赖；退役流程依 `maintenance-retirement` | 归档记录、目录清点 |

结构调整在 S3 与 S4 之间循环：移动与门禁校验交替推进，构建通过后才进入下一批移动。

## 门禁证据

| 门禁 | 证据形态 | 失效条件 |
|---|---|---|
| G2 | 项目形态选择理由、目录到模块与所有者映射、公开面设计、门禁方案 | 边界未经架构裁定、映射缺所有者 |
| G3 | 结构调整 diff、构建与导入检查输出、manifest 与所有者同步记录 | 跨包相对路径或未声明依赖仍在 |
| G4 | 导入检查、构建图与包导出校验输出、例外记录 | 门禁只在本地运行、例外无到期条件 |

证据来自实际运行的门禁输出；目录命名与审查记忆不构成边界证据。

## 交接与升级

- 从 `architecture-design` 接收边界、分层与依赖方向；未裁定的退回该 skill，不以目录现状代替裁定。
- 导入规则与构建图检查交 `testing-quality` 接入 CI；生成目录的格式化排除交 `code-style`；目录所有者映射交 `vcs-collaboration`。
- 升级：结构调整跨越多个包且无法独立回滚、门禁缺失导致边界无法检查时，报 Recycle 到 S2；强制规则冲突报告用户裁决。
- 停止：继续移动会扩大违规边或破坏构建时停止，报告受阻项与已完成项。

## 裁剪与度量

| 级别 | 裁剪 | 不可裁剪项 |
|---|---|---|
| R0 | 单目录重命名只做导入自检，不建新门禁 | 构建通过与导入一致 |
| R1 | 目录映射与门禁随增量提交，G4 至少一名非作者审查 | 构建图与导入检查 |
| R2 | 完整映射、包导出与独立审查，跨包移动分步回滚 | G4 的边界证据与回滚路径 |

度量：以跨包相对导入数、未声明依赖数与门禁绕过数为准；数值上升时先查映射与门禁，不得放宽规则。
