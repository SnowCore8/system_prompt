# 性能规范生命周期契约

本文件把性能规范接入 S0–S6 与 G0–G6：界定各阶段的输入、活动、输出与门禁，规定证据包与复核方式，给出交接
对象、升级条件、裁剪方式与度量口径。测量方法、瓶颈分类与取舍规则见 `dimensions.md`，工作表与优化记录模板见
`checklists.md`。

## 阶段职责

| 阶段 | 输入 | 活动 | 输出 | 门禁 |
|---|---|---|---|---|
| S0 受理 | 性能诉求、告警或容量预测 | 确认诉求是否属于性能问题，记录授权、风险级别与停止条件 | 受理结论与分流说明 | G0 |
| S1 探索 | 用户可感知的慢、SLO 或成本压力 | 建立现状基线，写明指标口径与“不优化”的后果，判断投入是否值得 | 基线数字与目标候选 | G1 |
| S2 计划 | 基线与目标候选 | 固定目标、预算、测量环境、基准脚本位置与停止条件 | 目标与预算表、基准计划 | G2 |
| S3 构建 | 目标、预算与基准计划 | 运行基线、剖析热点、归类瓶颈、单点变更与逐次复测 | 剖析输出、变更记录、逐次复测数据 | G3 |
| S4 验证 | 单点变更与前后数据 | 复核可比性、样本量与归因，裁掉无收益改动 | 前后对比表与验收结论 | G4 |
| S5 发布 | 验证结论与关键路径清单 | 取发布前快照，确认回归阈值、回滚触发条件与接受记录 | 发布前快照、回滚条件 | G5 |
| S6 收尾 | 发布后指标与优化记录 | 对照目标评估收益，登记残留瓶颈与后续项 | 收益对照与后续优化项 | G6 |

S0 的诉求若已被证实属于并发正确性问题，直接转交 `concurrency-conventions`，不进入 S1 的性能基线流程。

## 门禁证据

| 门禁 | 证据包 | 复核人 | 失效条件 |
|---|---|---|---|
| G1 | 现状基线、指标口径、用户影响与可选方案比较 | 产品负责人 | 指标不可测，或只有“感觉慢”的描述 |
| G2 | 目标与预算、基准脚本与输入集路径、测量环境、停止条件 | 项目负责人 | 目标无口径，或基准无法在固定环境重跑 |
| G4 | 前后对比数据、样本量与波动、热点与改动的对应关系、回滚方式 | 独立审查者 | 环境、输入或口径变化导致数字不可比 |
| G5 | 关键路径发布前快照、回归比对结论、回滚阈值与触发条件 | 发布负责人 | 关键路径无基线，或超阈值仍无接受记录 |
| G6 | 目标达成情况、无效优化回滚记录、残留瓶颈与负责人 | 项目负责人 | 收益无数据支撑，或后续项无负责人 |

证据组织：

- 每组数字写明脚本路径、输入集规模、硬件或容器规格、运行次数与统计量；单次运行的结果不作为证据。
- 剖析输出保留原始文件或采样摘要，并标注工具与版本；截图仅在无法导出原始文件时使用，并注明采集命令。
- 前后对比与优化记录一并附在变更或工单上，使未参与优化的人能够重跑。
- 目标或口径发生变化时，重新建立基线；旧基线在口径变更后不再作为 G4/G5 证据。

## 交接与升级

上游交接：

- 从 `project-lifecycle-governance` 的 G1/G2 接收目标与预算，确认目标口径与验收标准；本 skill 不改变 G1 的
  收益基线，只提供性能维度的数字。
- 从 `release-operations-conventions` 接收生产环境的性能告警；生产测量结论由该 skill 出具，本 skill 负责在
  开发环境复现与定位。
- 从 `architecture-and-design-conventions` 接收框架或数据流变更；变更前后各建立一次基线，避免跨版本比较。

下游交接：

- 基准接入 CI 的机制、阈值与告警策略交给 `testing-and-quality-conventions`；本 skill 只提供脚本与方法。
- 索引的 schema 约束、迁移与锁影响交给 `api-and-data-conventions`；本 skill 只给出“值得增设”的判断与写入
  成本估算。
- 优化过程中若改变外部行为，按 `refactoring-conventions` 的判定拆分行为变更与性能变更，分别提交与验证。
- 发布前快照与回归阈值交给 G5；残留瓶颈交给 S6 的收益对照与后续计划。

升级条件：

- 无可复现基准：停止优化，先补基准脚本；无法建立基准时报告障碍，不以“看起来慢”推进。
- 目标缺失且会影响范围、预算或验收标准：请求用户确认，不得以暂定目标冒充承诺。
- 优化需要跨模块改动、引入缓存层或更换数据存储：按范围规则重新确认，并补充回滚方案。
- 测量显示无显著收益：回滚改动并记录结论；同一路径连续两次优化无收益时，重新评估目标是否合理。

## 裁剪与度量

| 级别 | 性能工作的裁剪 | 不可裁剪项 |
|---|---|---|
| R0 | 复用已有基准脚本，单次复测与一行结论即可 | 优化前后使用同一套基准的对照 |
| R1 | 完整基准、剖析与优化记录，G4 由非作者复核 | 目标口径、归因关系与回滚方式 |
| R2 | 生产或关键路径变更增加独立复核与回滚演练，发布前快照留档 | 前后对比、回滚阈值与接受记录 |

度量口径：

| 指标 | 定义 | 用途 |
|---|---|---|
| 目标达成率 | 达到 G2 目标的路径占本次优化路径的比例 | 判断优化是否解决原问题 |
| 无效优化回滚率 | 复测无显著收益后回滚的改动占比 | 评估测量纪律与假设质量 |
| 基准噪声下限 | 同一基准重复运行的波动范围 | 判断差值是否可称为收益 |
| 性能回归逃逸 | 发布后才发现的关键路径回归数 | 评估 G4/G5 的覆盖 |
| 优化记录完整率 | 带有脚本、前后数字与结论的优化记录占比 | 评估可复现性 |

指标按迭代或按月复核；收窄统计范围、重定义指标或只报告有利分位均属失真。指标用于改进测量与设计，不用于
个人排名；异常时先检查环境漂移、输入变化与工具版本，再判断是否存在真实回归。R0 任务只在出现返工时记录指标。
