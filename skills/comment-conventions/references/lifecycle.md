# 注释规范生命周期契约

本文件说明注释在阶段与门禁中的位置：哪些契约必须随设计确定、哪些证据在构建与验证时取得、审查失败如何回退。
注释类型与写法细则见 `dimensions-api.md`、`dimensions-inline.md` 与 `dimensions-policy.md`，语言语法见
`languages.md`；阶段与门禁的定义由 `project-lifecycle-governance` 裁定。

## 阶段职责

| 阶段 | 输入 | 活动 | 输出 | 门禁 |
|---|---|---|---|---|
| S2 计划 | 接口契约、数据模型、文档工具链、仓库语言声明 | 确定哪些公开符号必须有文档注释；选定标签风格与文档生成器；声明注释语言；规划弃用与移除说明的落点 | 注释策略、工具配置、语言与标签约定 | G2 |
| S3 构建 | G2 的契约与工具配置、既有注释风格 | 为新增或变更的公开符号写契约；为不显而易见的选择写行内理由；标记带负责人与触发条件；生成的文档同步更新 | 注释 diff、标记与弃用条目、生成的文档 | G3 |
| S4 验证 | 增量、文档构建配置、linter 规则 | 重读注释核对签名与行为；运行文档构建、doctest 与注释 linter；搜索旧名称与被删代码的引用 | 构建与 doctest 输出、过时注释清单、lint 结果 | G4 |
| S5 发布 | 弃用清单、生成代码清单、发布说明草稿 | 核对弃用标记的移除版本与说明一致；确认生成文件未被手工编辑；核对发布说明与注释中的迁移路径 | 迁移路径记录、发布说明中的注释相关条目 | G5 |

注释工作的边界：

- 注释在 S3 与代码同批产生，不留给 S4 补写；S4 只验证一致性，不负责补齐契约。
- 涉及外部契约的注释变更按接口变更处理，先过 G2，再进入实现。
- 生成文件与引入文件的注释随生成器或上游更新，不在本地逐行修改。

## 门禁证据

G2 计划：

- 公开符号清单，标明哪些必须有文档注释、哪些可以省略及其理由。
- 契约覆盖范围：对外公开的符号与仅内部使用的符号分别列出，避免把内部实现写进公开文档。
- 文档生成器与注释 linter 的配置位置，以及本地与 CI 的运行方式。
- 仓库自然语言声明；跨语言仓库说明每种语言适用范围。
- 标记拼写与扫描工具的约定，确保到期标记能在构建中被发现。
- 弃用与移除的说明落点：标记位置、替代项命名、移除版本或日期。

G3 构建：

- 新增或修改的文档注释与签名逐项对应，含参数、返回值、错误、副作用与不变量。
- 示例与 doctest 的期望输出随行为同步更新，未留下旧输出。
- 每个标记的负责人、动作与触发条件；issue 或工单引用可解析。
- 工具指令取最窄范围并附理由，文件级抑制另有清理工单。
- 生成文件的标记完整，改动来自生成器而非手工编辑。
- 被删除代码不在注释中残留；临时禁用项带负责人、工单与到期时间。

G4 验证：

- 文档构建命令与真实输出、doctest 结果、注释 linter 结果，含退出码。
- 过时注释清单：与当前签名、默认值、错误类型或示例输出不一致的条目及修复状态。
- 旧名称搜索记录：函数名、参数名、默认值、返回类型与错误文本。
- 生成文件与引入文件的注释未被手工改动，标记仍与生成器一致。
- 注释中的机密与个人数据扫描结果；发现项按安全流程处理，不在本流程中清理证据。
- 注释语言一致性检查：同一仓库内未出现第二种自然语言。

G5 发布：

- 弃用标记的替代项与移除窗口与发布说明一致。
- 发布说明中的示例与当前 API 一致，不引用已删除的符号。
- 生成标记与生成器输出一致，发布物中未被手工改写。
- 若发布包含契约变更，附迁移片段与其所在位置的注释链接。

不满足时：G2 缺策略或工具配置时 Hold，退回计划；G3 出现裸标记、注释掉的代码或无主 TODO 时 Recycle 到 S3；
G4 文档构建或 doctest 失败、或行为已变而注释未同步时 Recycle，修复后重新验证；G5 弃用说明与标记不一致时
Hold 发布，补齐迁移说明后再过门。不得以“注释不影响运行”为由跳过 G4。

## 交接与升级

上游交接：

- 从 `api-and-data-conventions` 接收公开契约的语义，文档注释只描述该契约，不改写契约本身。
- 从 `naming-conventions` 接收规范名称，注释中的旧名属于缺陷，改名时同步搜索。
- 从 `code-style-conventions` 接收行宽、标点与 linter 配置；风格差异不进入注释内容评审。
- 从 `documentation-conventions` 接收术语与文档站边界；注释长成文档时迁移并链接。

下游交接：

- 向 `testing-and-quality-conventions` 交付 doctest 与文档构建的门禁命令，阈值由其配置。
- 向 `release-operations-conventions` 交付弃用标记与移除窗口，公告位置由其裁定。
- 向 `security-compliance-conventions` 上报注释中的凭据与个人数据，由其决定轮换与披露。
- 向 `refactoring-conventions` 交付注释随代码移动的规则，重构时不得留下孤立注释。
- 向 S6 复盘交付注释债清单与未关闭行动项，作为收尾核对的输入。

升级与停止：

- 注释中发现凭据、令牌或个人信息时立即停止编辑，保留现场并报告，不先删除行。
- 公开契约的语义需要变化时升级到 G2，由契约负责人确认；不得仅改注释使实现“看起来正确”。
- 生成文件缺少标记或标记被手工改动时，停止修改输出文件，转到生成器或来源。
- 文档工具与项目约定冲突时列出两种做法与影响，交由用户选择，不自行混用。

## 裁剪与度量

按风险裁剪：

| 级别 | 典型注释工作 | 证据厚度 | 审查 |
|---|---|---|---|
| R0 轻量 | 单个行内理由、拼写或标点修正 | 自检与 lint 即可 | 执行者自检 |
| R1 标准 | 多文件注释更新、公开函数契约调整 | 构建与 doctest 输出、过时注释清单 | 至少一名非作者审查 |
| R2 关键 | 公开 API 契约、弃用声明、法律头或生成标记变更 | 完整构建输出、迁移路径、法律与生成证据 | 契约与安全独立评审，人工批准 |

裁剪只减少记录篇幅，不减少验证：R0 也运行 lint，R1 不得省略构建，R2 不得省略迁移路径与法律头核对。

度量用于发现注释债：

- 文档构建与 doctest 的失败次数及修复时长。
- 过时注释数：审查中发现的与代码不一致条目，按变更统计。
- 构建耗时变化：文档工具或示例数量增长带来的门禁成本。
- 无主标记数：缺少负责人或触发条件的 TODO、FIXME、HACK。
- 注释密度异常文件数：逐行注释或完全无注释的极端文件。
- 公开符号契约覆盖率：有文档注释的公开符号占比。
- 生成文件手工编辑次数：审查中发现的绕过生成器的改动。
- 注释语言混用文件数：违反单一自然语言声明的文件。

指标恶化时先查根因：契约未在 S2 定清、工具未接入 CI，还是审查只读代码不读注释；不得通过删除注释或放宽
linter 改善数字。注释债进入待办，按 S3 的小步纪律清理，并在 S6 复盘时核对清理结果。
