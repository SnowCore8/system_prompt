# 生命周期度量

## 1. 生命周期度量
度量用于判断结果、发现阻塞、验证改进，不用于制造压力或替代门禁。一个能改变决策的度量值得保留；一个
只能证明“大家很忙”的度量应当删除。

- 先定义决策用途，再选择指标；没有使用场景的指标不采集。
- 结果指标优先于活动指标；流动指标优先于局部利用率。
- 每个指标有唯一口径、数据源、负责人、刷新频率与已知缺口。
- 基线先于目标；没有基线的目标只是愿望。
- 指标必须能追溯到原始记录；无法追溯的汇总值不得用于门禁或组合决定。
- 指标用于系统改进，不得用于个人排名、惩罚或绩效绑定。
- 单一指标不得替代门禁判断；指标恶化时先查根因，不得直接改口径或降目标。
- 数据缺失、样本过小或口径变化时，标注“不可比”，不得强行连线。

## 2. 指标目录

| 类别 | 指标 | 口径 | 决策用途 |
|---|---|---|---|
| 结果 | 收益实现 | 对照 G1 基线的实际收益 / 目标收益 | 继续、转向或退出 |
| 结果 | 采用率 | 目标用户中使用目标功能的比例 | 判断是否解决真实问题 |
| 结果 | 用户结果指标 | 完成关键任务的成功率、时长或错误率 | 判断体验是否改善 |
| 流动 | 前置时间 | 从受理到交付的日历时间 | 发现受理与排队瓶颈 |
| 流动 | 周期时间 | 从开始处理到完成的日历时间 | 发现批量与 WIP 问题 |
| 流动 | 吞吐 | 单位时间完成的条目数 | 判断产能与批次 |
| 流动 | 在制品 | 同时进行的条目数 | 控制并行与集成风险 |
| 流动 | 可预测性 | 承诺与实际交付的偏差 | 判断计划可信度 |
| 质量 | 逃逸缺陷 | 发布后发现的缺陷数与严重度 | 改进测试与评审 |
| 质量 | 变更失败率 | 导致回滚、热修或事故的发布比例 | 判断发布可靠性 |
| 质量 | 未验证项 | 未运行或未覆盖的测试与场景 | 判断证据完整性 |
| 运维 | 可用性 | 可用时间占全部时间的比例 | 判断服务健康 |
| 运维 | 事故数 | 单位时间的事故数量与严重度 | 判断运维负载 |
| 运维 | 平均恢复时间 | 从事故开始到恢复的时间 | 判断恢复能力 |
| 运维 | 告警误报率 | 无效告警占全部告警的比例 | 发现告警噪音 |
| 运维 | 恢复演练通过率 | 按计划完成的恢复演练比例 | 验证备份与回滚 |
| 治理 | 条件关闭率 | 到期关闭的 Conditional Go 条件比例 | 判断门禁是否有效 |
| 治理 | 证据完整率 | 门禁记录中可追溯证据的比例 | 判断记录质量 |
| 治理 | 风险老化 | 超过复审日期的风险数 | 发现治理停滞 |
| 治理 | 决策等待时间 | 从证据齐备到决定的时间 | 发现审批瓶颈 |
| 能力 | 审查周转 | 从提交审查到结论的时间 | 判断协作瓶颈 |
| 能力 | 自动化率 | 自动完成的验证占全部验证的比例 | 判断可重复性 |
| 能力 | 依赖健康 | 过期、有漏洞或无人维护的依赖比例 | 判断供应链风险 |
| 能力 | 知识集中度 | 关键模块的可维护者数量 | 判断交接风险 |

## 3. 门禁与组合度量

- G0：受理记录完整率、风险分级有依据的比例、停止条件缺失数。
- G1：收益基线覆盖率、选项比较完整率、关键假设未验证数。
- G2：验收标准可判定率、依赖确认率、回滚方案覆盖率、ADR 缺失数。
- G3：DoR 满足率、WIP 超限次数、增量可运行率、评审等待时间。
- G4：证据完整率、未验证项数、逃逸缺陷趋势、独立审查覆盖率。
- G5：回滚演练完成率、发布失败率、生产授权缺失数、观测覆盖缺口。
- G6：恢复演练通过率、告警误报率、平均恢复时间、值守覆盖缺口。
- G7：收益对照完成率、行动项关闭率、未关闭风险数、交接完成率。

组合层关注组合收益、容量利用、依赖健康、风险暴露、流动效率与退出质量；按月或按季度审查，不介入团队
迭代细节。门禁度量只用于判断证据是否足够，不用于给团队打分；指标不能替代判断。

## 4. 数据质量与反作弊

- 口径变化必须记录版本与生效日期；新旧口径不得直接连线比较。
- 样本过小、季节性或外部事件影响时，标注限制，不强行解释。
- 禁止通过缩小统计范围、重定义缺陷、关闭未完成条目、降低严重度或隐藏失败来改善指标。
- 指标异常时先问三个问题：数据是否可信、流程是否改变、目标是否仍成立；三者都排除后，再讨论绩效。
- 任何指标都不得成为惩罚个人的工具；发现这种使用时，报告并停止该指标的使用。

## 5. 审查节奏

R0 任务在交付时记录结果与验证；R1 在每个迭代或里程碑审查流动与质量；R2 在每个门禁审查证据完整率、
风险老化与条件关闭；组合层按月或按季度审查收益、容量与依赖。审查输出是决定与行动，不是报表；没有
决定或行动的指标审查应当停止。
