# naming 生命周期契约

本文件是 `naming` 的阶段契约：阶段职责、门禁证据、交接与升级、裁剪与度量。
阶段与门禁编号由 `project-lifecycle` 裁定；本文件只写本 skill 在各阶段的输入、活动、输出与证据形态。

## 阶段职责

| 阶段 | 输入 | 活动 | 产出与证据 |
|---|---|---|---|
| S0 受理 | 命名类请求：新建标识符、审查 diff 中的名称、执行重命名 | 复述对象与范围，判断名称的公开与共享范围 | 受理记录、风险级别 R0/R1/R2 |
| S1 需求 | 现有命名表、术语表、跨层名称用法 | 盘点不一致的名称与缺失的命名表条目，列出待决项 | 命名现状清单、禁用同义词草案 |
| S2 设计 | 接口契约、数据模型与发布方案 | 固定跨层名称契约，确定命名 lint 规则与重命名路径 | 命名表、跨层名称清单、lint 规则 |
| S3 构建 | G2 通过的名称契约 | 按各维度规则命名新增标识符；重命名按引用清单与回滚点执行 | diff 中的名称、命名表更新、引用清单 |
| S4 验证 | 增量与命名 lint 配置 | 核对跨层一致性，运行命名 lint，检查公开名称的别名或弃用路径 | lint 输出、跨层映射、别名或弃用证据 |
| S5 发布 | 验证证据 | 核对发布标签、发布说明与变更记录中的名称与命名表一致 | 标签与说明的一致性检查 |
| S6 运维 | 运行中的名称产物 | 依据日志、事件与指标字段名称排查命名不一致，归入修复待办 | 字段命名漂移记录 |
| S7 收尾 | 全程记录 | 复盘命名表是否被持续维护，遗留的同义词与重命名项移交 | 复盘记录、遗留项清单 |

## 门禁证据

G0：请求复述、授权依据、风险级别与停止条件；公开名称重命名按 R1 以上处理。
G1：命名现状清单与禁用同义词草案；未盘点的名称不得当作已确认事实。
G2：命名表、跨层名称清单、命名 lint 规则、重命名影响与回滚说明；缺命名表或公开名称未定时 Hold。
G3：命名 lint 输出、diff 与大小写矩阵一致、重命名引用清单；公开名称无别名或弃用路径时按 No-Go 阻断。
G4：跨层一致性核对、lint 通过记录、别名与弃用证据；修复后重验，无法兼容的公开改名退回 G2 重新确认。
G5：发布标签、发布说明与命名表一致；不一致时 Hold。
G6/G7：字段命名漂移记录与复盘记录；只作记录，不作为发布前门禁的替代。

## 交接与升级

上游交接：`architecture-design` 提供模块边界；`api-data` 提供契约与 schema；`project-structure` 提供目录与包边界；`vcs-collaboration` 提供分支与标签的流程规则。
下游交接：命名表与跨层清单交 `api-data` 与 `documentation`；命名 lint 规则交 `testing-quality` 接入 CI；发布标签与发布说明的一致性检查交 `release-operations`。

升级条件：公开名称重命名、跨仓库共享标识符、需要版本化或弃用的名称变更，退回 G2 重新确认并取得授权。
停止条件：命名表与既有契约冲突且授权范围内无法裁决时停止并报告冲突双方；不得在请求之外批量重命名。

## 裁剪与度量

裁剪：R0 只保留受理、一次验证与交付记录；R1 使用精简计划与 G4 非作者审查；R2 需独立审查，公开名称重命名需回滚演练。
命名表与 lint 规则不因裁剪而省略。

度量：同义词数量、命名 lint 违规数、公开名称漂移次数按基线比较趋势；指标恶化时先查根因，不调整阈值。度量不替代门禁判断。
