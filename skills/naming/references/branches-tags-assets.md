# 分支、标签与资产

## 1. 分支、标签与资产

- 分支名用 `type/short-description`：`feat/order-export`；描述用连字符分隔的简短 kebab-case，不用编号或人名。
- 发布标签用带 `v` 前缀的 SemVer：`v1.4.0`；预发布带后缀：`v1.4.0-rc.1`。
- 议题标签取小写受控集合，多词标签在连字符与空格之间只选一种写法；词表与维护人置于仓库中，新增条目先检查同义词。
- 静态资产文件名用 kebab-case，相关时带倍率或尺寸：`logo-dark.svg`、`hero-image@2x.png`。
- 文档文件用 kebab-case，ADR 编号用四位数字；锚点保持稳定，不随标题措辞变化。
- 域名、容器名与资源名使用小写 DNS 兼容名称；环境与所有者写入资源标签。
