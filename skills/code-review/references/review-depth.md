# 审查深度与风险分级

## 1. 审查深度与风险分级

- 风险三级：轻量（文档、注释、仅测试变更、格式化、补丁级依赖更新）；标准（功能、缺陷修复、次版本依赖
  更新）；高风险（认证、支付、权限、加密、数据迁移、公共接口、依赖主版本升级、CI 与发布工具）。
- 深度匹配风险：轻量核对一致性与拼写；标准核对正确性、测试充分性与边界；高风险逐行核对安全语义、错误
  路径与回滚。
- 审查者按所有权再按专长：归属团队必须有代表；未读过变更区域的审查者只能作评论者，不能作批准者。
- 审查人数按风险：轻量一名，标准一名所有者，高风险两名且含领域或安全审查者。
- 周转预期：一个工作日内首次响应；较小增量当日复审；停滞一日后改派，不得让作者无限等待。
- R1/R2 要求：R1 至少一名非作者审查；R2 两名独立审查者，执行者不得担任批准者。
