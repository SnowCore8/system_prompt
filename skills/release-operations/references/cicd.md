# CI/CD 与制品晋级

## 1. CI/CD 与制品晋级

- 只构建一次：通过 staging 的字节就是到达生产的字节；按环境重建会引入未测试的差异，并使回滚目标模糊。
- 阶段按失败成本自低至高排列：lint 与单元测试在前，集成与安全扫描居中，部署与冒烟在后；必需门禁在晋级
  前通过。
- 制品可复现：构建输入固定，锁文件与工具链版本随制品记录，可从干净检出重建。
- 发布作业在受保护环境中运行：环境机密只在该作业可用，云访问使用 OIDC 短期凭据；用 `concurrency` 阻止
  重叠部署；触发方式为 `release` 发布事件或带版本输入的 `workflow_dispatch`。
- 每个环境只接收从上一环境晋级来的同一制品；禁止为生产重新构建同一提交。
