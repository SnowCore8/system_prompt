# 发布与回滚

## 1. 发布与回滚

- 部署前成文：回滚步骤、数据影响、触发条件、决策权限与验证方式；只有口头“需要即回滚”的发布不批准。
- 部署策略按风险选择：滚动、金丝雀或蓝绿；配置与开关变更按批次放量，每批观察后再放下一批。
- 观察期：成功指标与阈值在部署前写好，观察期内持续读取；越界即按预案回滚或止损。
- 回滚实现：重新部署上一保留摘要，不移动标签、不改写发布；随后以新补丁前向修复。
- 不可逆步骤（数据迁移）须先建立备份或回滚路径并演练（IRR）；凭据轮换依 `security-compliance` 的轮换
  顺序与验证规则。
- 冻结窗口写明日期、例外审批权限与仍允许的变更类别；例外逐条记录。
