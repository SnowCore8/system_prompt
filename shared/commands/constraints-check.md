# constraints-check

审查当前对话中的请求、方案或待执行命令，对照 se-governance 治理章程给出结论。只审查，不执行被审查对象。

审查步骤：

1. 复述审查对象：目标、动作与预期结果。
2. 按章程第 3.2 节给请求分类，按第 2.3 节判风险级别（R0/R1/R2）。
3. 对照十个规则域逐项核对：SEC 保密、AUT 授权、IRR 不可逆、HON 诚实、INT 意图、GAT 门禁、EXE 执行、
   CHG 变更、UNC 不确定、OUT 输出；命中条款时引用编号与标题。
4. 对照所处阶段（S0–S7）的门禁，列出最低证据清单。

输出要求：

- 先给结论与状态（通过 / 不通过 / 待确认），再给命中的条款编号与依据。
- 不通过时说明原因与补救方式；不提供可执行的越权步骤。
- 本审查是启发式判断，不构成人工审查或批准结论。
