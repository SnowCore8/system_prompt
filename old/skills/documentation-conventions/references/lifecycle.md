# 文档规范生命周期契约

本文件把文档工作接入 S1–S6：说明每个阶段由谁交入什么、文档侧交付什么证据、何时需要升级，以及按风险级别如何
裁剪。正文给规则，本文件给阶段与门禁的对接方式。

## 阶段职责

| 阶段 | 输入 | 活动 | 输出 | 门禁 |
|---|---|---|---|---|
| S1 探索 | 问题陈述、目标读者、结果指标 | 判定读者与其要完成的任务；盘点已有页面，标出缺口与重复 | 读者定义、页面清单、缺口与负责人 | G1 |
| S2 计划 | 范围、设计决策、决策记录需求、发布计划 | 为每类页面选定模板；把文档任务写入计划，写明触发条件与负责人 | 文档任务清单、模板选型、审查触发条件 | G2 |
| S3 构建 | 增量、接口变化、配置变化 | 在同一个提交中改页面；保持单一权威归属；更新索引与导航 | 文档 diff、索引更新 | G3 |
| S4 验证 | 渲染后的站点、代码 diff、示例清单 | 构建、链接与拼写校验；逐条运行示例；对照代码核对事实 | 校验输出、示例运行记录、一致性结论 | G4 |
| S5 发布 | 版本号、分组变更条目、迁移字段 | 完成变更日志与发布说明；写迁移与弃用的映射、时间线与回滚 | 升级动作清单、迁移映射表 | G5 |
| S6 收尾 | 结果指标、偏差、遗留页面 | 写收尾报告；归档过时页面，留墓碑与重定向；移交负责人 | 收尾报告、归档与交接记录 | G6 |

阶段边界：S1 不写正式页面，只确认读者与缺口；S2 只出骨架与任务，不提前宣布行为；S3 的文档 diff 与代码 diff
同批；S4 以渲染结果为准；S5 只写已发生的事实；S6 只归档，不改写被归档页面的内容。

## 门禁证据

- G1 立项。证据为一位主读者、其要完成的任务、页面清单与缺口负责人；新页面尚无归属的，写明将替代或链接的
  对象。只有“需要补文档”的决心不构成证据。
- G4 验证。证据为文档构建的退出码与输出、内部死链为零的记录、示例运行结果，以及代码 diff 与文档 diff 的
  对应关系。构建失败、外部链接超时未复核、示例标注“未在 CI 校验”却不给手动步骤的，按未通过处理。
- G5 发布。证据为变更日志的分组条目、发布说明中的升级动作、迁移指南的映射表与回滚步骤、弃用的移除版本。
  仅写“各项改进与修复”的说明不构成发布证据。
- G6 收尾。证据为收尾报告中的偏差与教训、已归档页面的墓碑与重定向、移交后的负责人。空白归档目录不算证据。

证据与决定：

| 情形 | 决定 | 处理 |
|---|---|---|
| 构建与链接校验通过，文档 diff 覆盖全部可见变更 | Go | 进入下一阶段 |
| 迁移指南缺回滚，或弃用未写移除版本 | Conditional Go | 写明条件、负责人与到期日，条件关闭前不得发布 |
| 可见行为变化没有文档 diff | Recycle | 回到 S3 补齐后重新验证 |
| 页面与新行为冲突且无法确定权威归属 | Hold | 由架构或发布负责人裁定归属后再写 |
| 功能已移除而页面仍宣称可用 | No-Go（发布侧） | 先归档并重定向，再进入发布 |

## 交接与升级

上游交入：

- `project-lifecycle-governance` 给出阶段、风险级别与门禁日历；本 skill 据此决定文档证据的厚度。
- `architecture-and-design-conventions` 给出模块边界与决策结论；决策记录的正文结构由本 skill 管辖，编号由
  `naming-conventions` 管辖。
- `api-and-data-conventions` 给出契约与迁移字段；参考页从契约生成，不自行定义字段。
- `release-operations-conventions` 给出发布事实、公告位置与复盘触发条件；本 skill 只负责写法与结构。

下游交出：

- 交给 S4 的验证证据：构建输出、死链为零、示例运行记录。
- 交给 S5 的发布输入：分组条目、升级动作、迁移映射与弃用时间线。
- 交给 `repository-governance-conventions` 的归档结论：墓碑页、重定向与保留的 URL。

升级条件：

- 事实归属争议：两处都声称权威，或新页面与既有页面重复。升级到 `project-lifecycle-governance` 裁定；期间只
  更新较可信的一处，并记录争议。
- 结构无法落盘：生成器不支持必需章节、认证或示例。升级到生成器负责人；不得手工编辑产物绕过。
- 触发条件缺失：页面无人负责或无审查事件。升级到项目负责人补齐负责人，否则视为治理缺陷。
- 需要删除或批量归档：依 IR-1 与 AU-1 取得明确同意，并先核查入站引用。

停止条件：

- 契约未定稿而参考页需要字段清单时，停止编写，改为链接契约草案。
- 没有权威来源且新建页面必然产生副本时，停止编写，先解决归属。
- 迁移缺少回滚且数据不可逆时，停止“立即升级”的措辞，改为条件升级并写明验证步骤。

## 裁剪与度量

按风险裁剪：

| 级别 | 文档证据 | 可以省略 | 不得省略 |
|---|---|---|---|
| R0 | 更新权威页与一行变更日志 | 类型模板的次要章节、独立审查 | 权威归属、链接校验、当前事实 |
| R1 | 类型模板、构建与链接校验、独立审查 | 无迁移时省略迁移指南 | 文档 diff 与代码同批、负责人 |
| R2 | 完整模板、迁移与回滚、受众审查、归档计划 | 无 | 升级动作、回滚步骤、公开边界审查 |

度量：

| 指标 | 计算 | 用途 |
|---|---|---|
| 权威页重复率 | 抽查页面中与权威页重复的事实条数 | 判断副本是否仍在增长 |
| 死链数 | 构建中的内部死链计数 | 判断导航与重定向是否有效 |
| 文档 diff 覆盖率 | 有可见行为变化的提交中带文档 diff 的比例 | 判断同步是否落实 |
| 示例通过率 | CI 中可运行示例的通过比例 | 判断示例是否仍在教学 |
| 触发达成率 | 按审查触发条件实际审查的页面比例 | 判断归属是否有效 |

度量纪律：不以页面数、字数或提交数衡量文档质量；指标异常先查模板与索引是否失修，不得先改目标。审查抽查
优先覆盖阅读量最大的页面，其次覆盖最近改动的页面。
